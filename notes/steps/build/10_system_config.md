# System Configuration — ft_linux

Configure the running environment before building the kernel.
All commands run **inside the chroot** unless noted otherwise.

> **Automated:** `bash $FT_DIR/scripts/02_build/06_run_system_config.sh` (inside
> the chroot) runs `scripts/03_system/01_bootscripts.sh` and `02_system_config.sh`,
> which write everything below from `config/ft_linux.conf` (hostname = login,
> fstab from `VM_*_DEV`). This page explains the files; the scripts are the
> source of truth (LFS 12.4 §9.2–9.9, §10.2).

---

## Network

```bash
# hostname — must be your student login (subject requirement)
echo "everonel" > /etc/hostname

# /etc/hosts
cat > /etc/hosts << "EOF"
127.0.0.1   localhost
127.0.1.1   everonel
::1         localhost ip6-localhost ip6-loopback
EOF

# /etc/resolv.conf — use a public resolver
cat > /etc/resolv.conf << "EOF"
nameserver 8.8.8.8
nameserver 8.8.4.4
EOF
```

## SysV init scripts

Install the LFS bootscripts package (provides `/etc/rc.d/`, `/etc/inittab`, etc.):

```bash
cd /sources && tar -xf lfs-bootscripts-*.tar.xz && cd lfs-bootscripts-*/
make install
cd /sources && rm -rf lfs-bootscripts-*/
```

> If the tarball is missing, download it from outside the chroot:
> ```bash
> wget -P /mnt/lfs/sources \
>   https://www.linuxfromscratch.org/lfs/downloads/stable/lfs-bootscripts-20230728.tar.xz
> ```

**`/etc/inittab`** — lfs-bootscripts installs `inittab.d/` fragments but NOT the file
itself; sysvinit requires `/etc/inittab` directly. Create it:

```bash
cat > /etc/inittab << "EOF"
# Begin /etc/inittab

id:3:initdefault:

si::sysinit:/etc/rc.d/init.d/rc S

l0:0:wait:/etc/rc.d/init.d/rc 0
l1:S1:wait:/etc/rc.d/init.d/rc 1
l2:2:wait:/etc/rc.d/init.d/rc 2
l3:3:wait:/etc/rc.d/init.d/rc 3
l4:4:wait:/etc/rc.d/init.d/rc 4
l5:5:wait:/etc/rc.d/init.d/rc 5
l6:6:wait:/etc/rc.d/init.d/rc 6

ca:12345:ctrlaltdel:/sbin/shutdown -t1 -a -r now

su:S016:once:/sbin/sulogin

1:2345:respawn:/sbin/agetty --noclear tty1 9600
2:2345:respawn:/sbin/agetty tty2 9600
3:2345:respawn:/sbin/agetty tty3 9600
4:2345:respawn:/sbin/agetty tty4 9600
5:2345:respawn:/sbin/agetty tty5 9600
6:2345:respawn:/sbin/agetty tty6 9600

# End /etc/inittab
EOF
```

**Clock configuration:**

```bash
cat > /etc/sysconfig/clock << "EOF"
UTC=1
EOF
```

**Console configuration:**

```bash
cat > /etc/sysconfig/console << "EOF"
KEYMAP="us"
FONT="lat2a-16 -m 8859-2"
EOF
```

**Network interface configuration** (DHCP on first ethernet):

```bash
cat > /etc/sysconfig/ifconfig.eth0 << "EOF"
ONBOOT=yes
IFACE=eth0
SERVICE=dhcpcd
DHCP_START="-b -q -t 30"
DHCP_STOP="-k"
EOF
```

> The kernel is booted with `net.ifnames=0` (see grub.cfg), so the first NIC is
> always `eth0`. `SERVICE=dhcpcd` needs dhcpcd and its BLFS service script.

## /etc/fstab

```bash
# generated by scripts/03_system/02_system_config.sh (from VM_*_DEV); equivalent to:
cat > /etc/fstab << "EOF"
# <file system>  <mount point>  <type>  <options>           <dump>  <pass>
/dev/sda2        /              ext4    defaults             1       1
/dev/sda1        /boot          ext4    defaults             1       2
/dev/sda3        none           swap    sw                   0       0
proc             /proc          proc    nosuid,noexec,nodev  0       0
sysfs            /sys           sysfs   nosuid,noexec,nodev  0       0
devpts           /dev/pts       devpts  gid=5,mode=620       0       0
tmpfs            /run           tmpfs   defaults             0       0
devtmpfs         /dev           devtmpfs mode=0755,nosuid    0       0
tmpfs            /dev/shm       tmpfs   defaults             0       0
EOF
```

> Adjust `/dev/sdaX` device names to match your actual VM disk layout.
> Verify with `lsblk` or `blkid` from outside the chroot.

## Networking for the evaluation (BLFS 12.4)

The evaluation asks the distro to **download sources and install packages**,
so steps 5–9 of `06_run_system_config.sh` add (tarballs and md5 in
`config/extra-sources.list`, downloaded with the LFS sources):

| Script | Package | Why |
|---|---|---|
| `05_libtasn1.sh` | libtasn1 4.20.0 | needed by p11-kit |
| `06_p11kit.sh` | p11-kit 0.25.5 | `trust` tool used by make-ca |
| `07_make_ca.sh` | make-ca 1.16.1 | CA certificates in `/etc/ssl/certs`, `/etc/pki/tls/certs/ca-bundle.crt`. `make-ca -g` downloads Mozilla's `certdata.txt` with `openssl s_client` → **needs network in the chroot** |
| `08_wget.sh` | Wget 1.25.0 | HTTPS downloads (OpenSSL), smoke test against linuxfromscratch.org |
| `09_dhcpcd.sh` | dhcpcd 10.2.4 + blfs-bootscripts | DHCP at boot via `/etc/sysconfig/ifconfig.eth0` (`SERVICE=dhcpcd`) |

After boot (VirtualBox NAT, Intel PRO/1000): `ip addr show eth0` should have an
address, then `wget https://ftp.gnu.org/gnu/hello/hello-2.12.tar.gz` must work.
